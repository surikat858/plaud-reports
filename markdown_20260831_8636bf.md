## 📌 О проекте

**Plaud Reports** – это набор PowerShell-скриптов для автоматического получения расшифровок, саммари и списка задач из записей [Plaud](https://plaud.ai) и отправки их на почту.  
Решение предназначено для пользователей Windows, которые хотят автоматизировать процесс обработки встреч и отправки отчётов без ручного участия.

Автор: [surikat858](https://github.com/surikat858)

## 🚀 Что сделано

- ✅ **Два варианта скрипта**:
  - `send-plaud-report.ps1` – интерактивный (показывает ход выполнения в консоли).
  - `send-plaud-report-scheduled.ps1` – для Планировщика заданий (без ввода с клавиатуры).
- ✅ **Поддержка нескольких получателей**.
- ✅ **Подробное логирование** в папку `PlaudReports` (лог-файлы по дням).
- ✅ **Автоматическая ротация старых файлов** (удаление логов и отчётов старше 14 дней).
- ✅ **Работа с кириллицей** (кодировка UTF-8 с BOM).
- ✅ **Проверка новых записей** – отправляются только те, которых ещё нет в `plaud_sent.log`.
- ✅ **Отображение хода выполнения** – в интерактивном режиме виден прогресс обработки каждой записи.

## 🔧 Как работает

1. Скрипт запускается (вручную или по расписанию).
2. Выполняет команду `plaud today` для получения списка записей за текущий день.
3. Извлекает идентификаторы записей (32-символьные хеши).
4. Сравнивает их с уже отправленными ID (лог `plaud_sent.log`).
5. Для каждой новой записи по очереди:
   - Получает транскрипцию (`plaud transcript <ID>`).
   - Получает саммари (`plaud summary <ID>`).
   - Получает задачи (`plaud tasks <ID>`).
   - Формирует текстовый отчёт и сохраняет его в `PlaudReports`.
   - Отправляет письмо с вложением на все указанные адреса.
6. Записывает обработанные ID в лог, чтобы не дублировать отправку.
7. Удаляет файлы старше 14 дней.

## 📦 Требования

- **Windows 10/11** (PowerShell 5.1+).
- **Установленный Node.js** (для Plaud CLI).
- **Plaud CLI** – глобально (`npm install -g @plaud-ai/cli`).
- **Авторизация** в Plaud (`plaud login`).
- **Учётная запись SMTP** (логин/пароль).
